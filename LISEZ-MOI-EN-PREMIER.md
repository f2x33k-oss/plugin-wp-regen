## ⚡ INSTALLATION RAPIDE

### 1. Installer (2 min)

```
WordPress → Extensions → Ajouter
→ Téléverser
→ Choisir ai-content-factory-pro.zip
→ Installer
→ Activer
```

### 2. Configurer (1 min)

```
AI Content Factory → Réglages

OBLIGATOIRE:
→ Clé API OpenAI: [VOTRE_CLÉ]

PRÉ-CONFIGURÉES (fonctionnent déjà):
→ Clé RapidAPI (Midjourney): ✅
→ Clé RapidAPI (Pinterest): ✅

→ [Enregistrer]
```

**Note** : Les autres APIs (SDXL, Flux, etc.) sont **à configurer manuellement** si vous voulez les utiliser.

### 3. Tester (2 min)

```
⚠️ IMPORTANT: Ouvrir Console (F12) !

AI Content Factory → Albums Recettes

Console doit afficher:
"AICFP: Initialisation Albums Recettes OK" ✅

Remplir:
- Titre: 1 recette de gratin dauphinois
- ✅ Générer les textes
- API: Midjourney (par défaut)
- Email: votre@email.com

Estimateur doit montrer:
🍽️ 1 • 💰 $0.07 • ⏱️ 3 min

[🔨 Lancer la génération]

Résultat:
→ ✅ Notification "Album ajouté"
→ 🔄 Redirection vers Instances (2.5s)
→ Tâche visible avec highlight bleu
→ Attendre 2-3 minutes
→ Status "Terminée" ✅
→ [📄 Voir l'article]
```

## 🔑 IMPORTANT : Clés API

### Clé RapidAPI Pré-Configurée

**Fonctionne pour** :
- ✅ Midjourney (génération images)
- ✅ Pinterest (recherche images)

**NE FONCTIONNE PAS pour** :
- ❌ SDXL, SDXL Food LoRA
- ❌ Flux Pro, Nanobanana
- ❌ Autres APIs RapidAPI

### Pour Utiliser les Autres APIs

1. Allez sur https://rapidapi.com/
2. Créez un compte (gratuit)
3. Abonnez-vous à l'API souhaitée
4. Copiez VOTRE clé RapidAPI
5. Collez dans Réglages

**Recommandé pour recettes** : SDXL Food LoRA ($0.02/image vs $0.05 Midjourney)
